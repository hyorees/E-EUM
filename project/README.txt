# AI 재난 전력복구 의사결정 지원시스템 - 시연용 프로토타입

## 핵심 시나리오
1. 태풍 발생
2. 전국 여러 지역에서 정전 피해 발생
3. 정전 지역과 시설/인구 데이터를 수집
4. AI가 피해 규모, 영향 인구, 중요시설, 예상 복구시간, 연쇄 영향 등을 종합
5. 지역별 복구 우선순위를 산정
6. 정전 영향도를 시간대별로 예측
7. 복구 전략을 여러 시나리오로 시뮬레이션
8. 담당자가 시뮬레이션 결과를 비교하여 복구 순서를 결정

## 현재 화면
- 전국 정전 피해 지도: 우선순위별 색상 구분
- AI 복구 우선순위 TOP 5
- 선택 지역의 AI 판단 근거
- 향후 6시간 정전 영향도 예측
- 3개 복구 시나리오 비교

## 주의
모든 데이터와 AI 점수는 공모전 시연을 위한 가상 데이터입니다.
현재 버전은 실제 전력망/기상/시설 API에 연결하지 않은 프론트엔드 시제품입니다.
